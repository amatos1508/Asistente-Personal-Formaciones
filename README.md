
# Asistente Personal de Formaciones

Aplicación privada para gestionar formaciones, sesiones, instructores y cuentas de videoconferencia.

## Objetivos

- Calendario propio con vistas de día, semana y mes.
- Gestión de formaciones abiertas y para empresas.
- Planificación de sesiones con Webex y Microsoft Teams.
- Seguimiento de instructores, participantes y certificaciones.
- Informes de asistencia y estadísticas anuales.

## Principios técnicos

- Proyecto independiente, sin reutilizar otros repositorios ni bases de datos.
- Autenticación y autorización seguras.
- Protección de datos personales.
- Secretos fuera del código fuente.
- Desarrollo por fases y pruebas antes de desplegar.
